# Convert a model matrix to long format

Convert a model matrix to long format

## Usage

``` r
augment_matrix_long(values, index, variable_names, value_name)
```

## Arguments

- values:

  A numeric matrix.

- index:

  Observation indices.

- variable_names:

  Variable names.

- value_name:

  Name of the resulting value column.

## Value

A tibble in long format.
