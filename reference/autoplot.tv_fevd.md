# Autoplot FEVD results

Autoplot FEVD results

## Usage

``` r
# S3 method for class 'tv_fevd'
autoplot(object, .response = NULL, .shock = NULL, ...)
```

## Arguments

- object:

  A \`tv_fevd\` object.

- .response:

  Optional response variables to display.

- .shock:

  Optional shocks to display.

- ...:

  Additional arguments reserved for future use.

## Value

A \`ggplot\` object.
